# Контроллер роборуки J1 + J2 v2

Это новая тестовая прошивка для двух осей. Старая рабочая версия `motor1_safe_test` не изменена.

## Что изменилось принципиально

- STEP больше не формируется вручную через `micros()` и `digitalWrite()` в основном цикле.
- Для каждой оси используется отдельный аппаратный RMT-канал ESP32 через `FastAccelStepper`.
- Есть ограничение скорости, разгон, торможение и плавное нарастание ускорения.
- Отпускание кнопки вызывает управляемое торможение.
- `Esc` и красная кнопка вызывают аварийную остановку.
- При потере heartbeat от программы ESP32 сама прекращает движение не позднее чем через 600 мс.
- Панель показывает скорость выходного сустава в градусах в секунду, учитывая редуктор 1:71.

## Зафиксированная распиновка

| Ось | ESP32 | LERDGE TMC2209 |
|---|---|---|
| J1 | `D25 / GPIO25` | `STEP` |
| J1 | `D26 / GPIO26` | `DIR` |
| J2 | `D32 / GPIO32` | `STEP` |
| J2 | `D33 / GPIO33` | `DIR` |
| обе | `3V3` | оба `VIO` |
| обе | общий `GND` | `GND` каждого драйвера |

На каждом драйвере `ENN/EN` сейчас соединён с его собственным `GND`, поэтому силовая часть постоянно разрешена. `VM` получает +12 В, а GND рядом с VM — минус 12-вольтового БП.

Перед подключением каждого мотора отдельно прозвони его реальный кабель. Цвета кабелей уже оказались разными. На одном рабочем кабеле пары были `чёрный + синий` и `красный + зелёный`; это не является универсальным стандартом для второго кабеля.

## Почему старая скорость казалась крошечной

При 200 полных шагах/оборот, 1/8 микрошаге и редукторе 1:71:

- мотору нужно 1600 STEP-импульсов на оборот;
- выходному суставу нужно 113600 импульсов на оборот;
- 1°/с на выходе = примерно 315,56 имп/с;
- 2000 имп/с = только 6,34°/с на суставе;
- измеренный потолок 7258 имп/с = примерно 23°/с на суставе и 272 об/мин мотора.

| Скорость сустава | Частота STEP | Обороты мотора |
|---:|---:|---:|
| 5°/с | 1578 имп/с | 59 об/мин |
| 10°/с | 3156 имп/с | 118 об/мин |
| 15°/с | 4733 имп/с | 177 об/мин |
| 20°/с | 6311 имп/с | 237 об/мин |
| 23°/с | 7258 имп/с | 272 об/мин |
| 30°/с | 9467 имп/с | 355 об/мин |

На собранной механике с 12-вольтовым питанием 7258 имп/с отработали устойчиво, а около 7500 имп/с начались громкий писк и потеря синхронизации. Поэтому 7258 имп/с теперь является жёстким пределом и панели, и прошивки ESP32 для обеих осей. Для обычной работы оставлен запас: профиль 20°/с = 6311 имп/с. Строка 30°/с показана только для понимания расчёта и сейчас программно недоступна.

## Первый запуск после подключения J2

1. Не подключай и не отключай разъём мотора при включённых 12 В.
2. Механически поддержи плечо, чтобы оно не упало при ошибочном направлении.
3. Подключи USB к ESP32 и залей прошивку.
4. Подай 12 В и подожди минимум одну секунду до первого движения. Это даёт StealthChop2 время выполнить первую фазу автонастройки в неподвижном состоянии.
5. Запусти `START_ARM_CONTROL.cmd`.
6. На J1 выбери `Тихо`, коротко проверь оба направления.
7. На J2 выбери `Тихо`, коротко проверь оба направления.
8. Только после этого переходи к `Нормально`, затем при необходимости к `Предел 7258`.

## Как был найден реальный максимум

Испытание 2026-08-29 зафиксировало границу: 7258 имп/с работает, около 7500 имп/с появляется устойчивый писк и ротор теряет синхронизацию. Это не ограничение ESP32/RMT: генератор импульсов имеет большой запас. Симптом означает нехватку доступного момента двигателя на оборотах в текущей конфигурации 12 В + StealthChop + примерно 1,14 А RMS + реальная механическая нагрузка.

Калибровать каждую ось отдельно и в наиболее тяжёлом положении руки.

### 1. Найти потолок скорости

1. Поставить разгон около 12–20°/с² и S-плавность 500–700 STEP.
2. Начать с 5°/с.
3. Увеличивать скорость по 5°/с и каждый раз двигаться несколько секунд в обе стороны.
4. Первые признаки потери синхронизации: изменение тона, внезапное падение момента, остановка ротора при продолжающемся писке, рывок выходного вала.
5. Жёсткий предел установлен ровно 7258 имп/с по просьбе пользователя; для регулярной работы рекомендуется профиль 20°/с (6311 имп/с), оставляющий запас до срыва.

### 2. Настроить ускорение

1. Поставить скорость не выше 70% найденного потолка.
2. Повышать ускорение небольшими шагами.
3. Если проблема появляется только на старте или остановке, уменьшить ускорение либо увеличить `S-плавность`.
4. Для тяжёлого J2 нормальное ускорение почти наверняка окажется ниже, чем для J1.

### 3. Настроить S-плавность

- `0` означает обычный трапецеидальный разгон с мгновенным появлением заданного ускорения.
- 300–700 STEP — разумная стартовая зона для этой передачи.
- Большее число смягчает начало и конец, но делает управление менее отзывчивым.
- Если мотор гудит в узкой полосе скорости, увеличение плавности не всегда помогает: иногда полезнее безопасно проходить резонансную полосу быстрее, то есть немного увеличить ускорение. Делать это только маленькими шагами.

## Что означает конкретный симптом

| Симптом | Наиболее вероятная причина |
|---|---|
| Только дрожит и не крутится даже на 5°/с | Перекрещены пары обмоток, оборван провод или плохая пайка |
| Нормально стартует, затем срывается на большой скорости | Не хватает момента на оборотах: 12 В, ток, StealthChop, нагрузка или слишком высокая цель |
| Рывок только при старте/стопе | Слишком высокое ускорение или слишком маленькая S-плавность |
| Сильная вибрация только в узком диапазоне | Резонанс мотора/механики |
| Работает без плеча, но с плечом срывается | Нагрузочный момент J2 и ускорение выше реального запаса |
| Драйвер периодически отключается после нагрева | Перегрев; нужен радиатор/обдув и проверка тока |

## Ток и следующий аппаратный предел

Измеренный `VREF = 1,293 В`. Для официальной схемы LERDGE с `Rsense = 0,11 Ом` её формула даёт примерно `IRMS = 0,88 × VREF ≈ 1,14 А`. Это безопасная тестовая величина, но ниже номинальных 1,5 А указанных моторов, поэтому часть момента сознательно не используется.

Сначала настраивается программный профиль. Повышать VREF следует только отдельным этапом, с радиатором, контролем температуры и учётом длительного предела модуля 1,4 А RMS. Если даже после этого скорости недостаточно, следующие варианты — UART-гибрид StealthChop/SpreadCycle либо 24-вольтовое моторное питание. Оба варианта требуют отдельной проверки проводки и защиты; текущая прошивка их не притворяется поддерживающей без физических соединений.

## Сборка и запуск из терминала

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32 ".\arm\firmware\arm_controller_v2"
arduino-cli upload -p COM7 --fqbn esp32:esp32:esp32 ".\arm\firmware\arm_controller_v2"
python ".\arm\firmware\arm_controller_v2\arm_control_panel.py"
```

Зависимости: Arduino-библиотека `FastAccelStepper 1.2.7` и Python-пакет `pyserial`.

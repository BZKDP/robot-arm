# Стенд одного сустава: ESP32 + TMC2209 + NEMA17 + AS5600

Цель стенда: подключить один мотор к питанию через драйвер, подключить ESP32 к ПК по USB, прочитать AS5600 и вручную покрутить мотор из программы на ПК.

## Что используем

- ESP32 DevKit.
- Драйвер TMC2209.
- Мотор NEMA17.
- БП 12-24В для мотора.
- AS5600 + магнит.
- WAGO/клеммники, провода, USB-кабель.

## Провода

### TMC2209

| TMC2209 | Куда |
|---|---|
| `VM` / `VMOT` | `+` БП 12-24В |
| `GND` рядом с VM | `-` БП |
| `A1/A2` | первая катушка мотора |
| `B1/B2` | вторая катушка мотора |
| `VIO` / `VCC` | `3V3` ESP32 |
| `GND` логики | `GND` ESP32 и `-` БП |
| `STEP` | `D12` ESP32 |
| `DIR` | `D14` ESP32 |
| `EN` | не подключаем, если на твоём TMC2209 нет такого пина |

Важно: мотор не подключать напрямую к БП. Только в `A1/A2/B1/B2` драйвера.

Катушки мотора найти мультиметром: два провода одной катушки имеют маленькое сопротивление между собой. Если мотор только дрожит, пары катушек перепутаны.

### AS5600

| AS5600 | Куда |
|---|---|
| `VCC` | `3V3` ESP32 |
| `GND` | общий `GND` |
| `SDA` | GPIO21 ESP32 |
| `SCL` | GPIO22 ESP32 |
| `DIR` | `GND` или не трогать |

Магнит должен быть строго над центром чипа AS5600, обычно зазор 1-2 мм.

## Порядок включения

1. Собрать только ESP32 + AS5600, без питания мотора.
2. Залить прошивку `one_joint_esp32`.
3. Запустить `joint_monitor.py`, подключиться к COM-порту, нажать `SCAN I2C`.
4. Убедиться, что найден адрес `0x36`, а `STATE ok=1`, `deg` меняется при вращении магнита.
5. Подключить TMC2209 к ESP32: `STEP/DIR/VIO/GND`. `EN` пока не трогаем.
6. Подключить мотор к `A1/A2/B1/B2`.
7. Выставить ток TMC2209 маленьким для первого теста, поставить радиатор.
8. Подать 12-24В на `VM/GND` драйвера.
9. В программе нажать `EN ON`, затем удержать `JOG +` или `JOG -` на скорости 100-200.
10. Если направление для `GOTO` обратное, нажать `INV 1`.

## Прошивка

```powershell
cd "$env:USERPROFILE\Desktop\роборука\arm\one_joint_stand\one_joint_esp32"
arduino-cli compile --fqbn esp32:esp32:esp32 .
arduino-cli upload -p COM3 --fqbn esp32:esp32:esp32 .
```

COM-порт подставить свой. Сейчас на ПК видны `COM3` и `COM4`.

## ПК-монитор

```powershell
cd "$env:USERPROFILE\Desktop\роборука\arm\one_joint_stand"
python .\joint_monitor.py
```

Команды можно слать вручную:

- `EN 1` - включить драйвер.
- `EN 0` - выключить драйвер.
- `JOG 200` - крутить вперед 200 шагов/с.
- `JOG -200` - крутить назад.
- `STOP` - остановить.
- `ZERO` - сделать текущий угол нулём.
- `GOTO 90` - ехать к 90 градусам по AS5600.
- `INV 1` / `INV 0` - поменять направление.
- `SCAN` - поиск I2C-датчиков.
